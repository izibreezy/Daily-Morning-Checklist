# Morning Checklist PWA

## Быстрый старт (GitHub Pages)
1. Создай репозиторий и залей содержимое этого архива в корень репо.
2. GitHub → Settings → Pages → Deploy from a branch → main / (root).
3. Открой получившийся HTTPS URL в Safari на iPhone.
4. Share → Add to Home Screen.

## Использование
- "Настройки" → редактируй пункты (добавить/удалить/переименовать/переставить).
- "Экспорт" — скопирует JSON (рекомендую сохранять в iCloud/Files).
- "Импорт" — восстановление из JSON.

## Файлы
- index.html — приложение
- manifest.webmanifest — манифест PWA
- sw.js — офлайн кэш
- icons/ — иконки
